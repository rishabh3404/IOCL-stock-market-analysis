# IOCL Stock Market Analysis

Stock market analysis project focused on Indian Oil Corporation Limited (IOCL) using SQL and Power BI.

## 📌 Project Overview

This project analyzes historical IOCL stock market data to understand price movements, trading patterns, and time-based performance.

The analysis uses SQL for data preparation and analytical queries, while Power BI is used to create an interactive dashboard.

## 🎯 Objectives

- Analyze historical IOCL stock prices
- Calculate key stock market metrics
- Study OHLC (Open, High, Low, Close) patterns
- Analyze daily, weekly, quarterly, and yearly trends
- Identify high and low price periods
- Create an interactive Power BI dashboard
- Generate business-friendly insights

## 🛠️ Technology Stack

- SQL
- Power BI
- DAX
- Data Cleaning
- Data Analysis
- Data Visualization
